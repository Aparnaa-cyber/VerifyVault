# 🔐 VerifyVault

VerifyVault is a blockchain-inspired certificate verification system that ensures secure and tamper-proof validation using SHA-256 hashing and Algorand blockchain transactions.

## 🚀 Features
- 📄 Upload and store certificates securely  
- 🔐 SHA-256 hash generation  
- 🔗 Store hash on Algorand Testnet (transaction note)  
- 🆔 Unique Transaction ID (TX ID) for each certificate  
- ✔️ Tamper-proof verification system  

## ⚙️ How It Works
1. User uploads a certificate  
2. System generates a SHA-256 hash  
3. Hash is stored on Algorand blockchain as a transaction  
4. During verification:
   - File is hashed again  
   - Compared with stored hash  
   - Match → ✅ Verified  
   - Mismatch → ❌ Invalid  

## 🛠️ Tech Stack
- HTML, CSS, JavaScript  
- CryptoJS (SHA-256 hashing)  
- Algorand Testnet (Blockchain)  

## 🔗 Blockchain Integration
Certificate hashes are stored as transaction notes on Algorand Testnet, ensuring immutability and secure verification.

## 🎯 Use Case

- Recruiters / HR verification
